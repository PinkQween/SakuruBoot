SakuruBoot /sɑːkʊɹuːbuːt/

A lightweight UEFI & BIOS bootloader with config-driven
OS selection, LUKS1/2 encryption, and dual x86_64 / AArch64 support.

Read the docs View on GitHub
🔐

LUKS Encryption

Full LUKS1 and LUKS2 unlock directly in the bootloader. Supports PBKDF2, Argon2id, XTS-AES, CBC-ESSIV, and masked passphrase entry.

⚡

UEFI & BIOS

Native UEFI PE32+ binary for modern firmware. Legacy MBR BIOS stage 1 / stage 2 for older hardware. Single codebase.

🏗️

Dual Architecture

Builds to x86_64-w64-mingw32 PE and AArch64 flat ELF. Extend to new targets with a few Makefile lines.

📄

Config-Driven

Human-readable sakuru.cfg for OS entries, default selection, timeouts, kernel args, and initrd paths.

🪶

Freestanding C11

Zero stdlib dependencies — -ffreestanding -nostdlib. Every helper is hand-rolled. Fits comfortably in the EFI partition.

🔓

Open Source

MIT licensed. Hack it, fork it, ship it. Contributions welcome — from crypto backends to new filesystem drivers.

Configuration

Drop a sakuru.cfg at the root of your EFI partition. Entries map human-readable names to kernels, initrds, and cmdlines. Encryption is a one-liner. 

; sakuru.cfg — example configuration

default = Arch Linux
timeout = 5

entry {
    title   = Arch Linux
    kernel  = /vmlinuz-linux
    initrd  = /initramfs-linux.img
    cmdline = root=/dev/sda2 rw quiet
}

entry {
    title      = Arch Linux (encrypted)
    kernel     = /vmlinuz-linux
    initrd     = /initramfs-linux.img
    cmdline    = root=/dev/mapper/root rw quiet
    encrypted  = yes
    luks_tries = 3
}
